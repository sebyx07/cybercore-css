# Stack

> established by the developerz.ai maintainer agent for the maintainers of this repository from what onboarding read and ran in this repo, then owned by
> its maintainers. Correct it in place; setup never overwrites a page that exists.

Frontend: Pure CSS/SCSS (no framework), 48 SCSS files. Build: Sass 1.80 for SCSS → CSS compilation, PostCSS 8.4 with Autoprefixer and CSSNano for optimization. Demo: React 18.3, Vite 5.4 (dev server), Vite build (production). Testing: Vitest 2.0 (unit tests), Playwright 1.48 (visual regression). Linting: Stylelint 16.10 (SCSS), ESLint 8.57 (TypeScript), Prettier 3.3 (formatting). TypeScript 5.6 strict mode. Node 20+ required. GitHub Actions for CI/CD (Node 20, npm 9+). No runtime dependencies in framework.
