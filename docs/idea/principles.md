# Principles

> established by the developerz.ai maintainer agent for the maintainers of this repository from what onboarding read and ran in this repo, then owned by
> its maintainers. Correct it in place; setup never overwrites a page that exists.

Pure CSS first: framework has zero JavaScript dependencies, React demo only. Modularity: import only what you need via layer-based cascade or SCSS modules. Design system: single source of truth for colors/spacing via CSS custom properties. Accessibility: all animations respect `prefers-reduced-motion`, keyboard navigation supported. Cyberpunk aesthetics: neon glows, dark backgrounds, tech-inspired effects. Framework-agnostic: works with any HTML/CSS stack, not tied to React/Vue/etc. Maintainability: BEM naming, strict layer organization, comprehensive tests. Zero breaking changes: semantic versioning, demo shows all public API surfaces.
