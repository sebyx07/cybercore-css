# Overview

cybercore-css is a pure CSS cyberpunk design framework: neon components, effects, utilities, design
tokens and 150+ SVG icons, published to npm as `cybercore-css` and served by jsDelivr and unpkg. A
page uses it from one `<link>` tag and `cyber-*` classes on plain HTML; Sass users import the whole
bundle or single modules. There is no JavaScript runtime: state is styled from native HTML state and
ARIA attributes.

The repository also holds the documentation site (`demo/`, React + Vite, deployed to GitHub Pages
at https://sebyx07.github.io/cybercore-css/), which consumes the framework as a user would.

It is a public project with outside contributors, maintained by the developerz.ai agent under the
policy in `.dz/maintainer/maintainer.yml`. Where things live: `CLAUDE.md` § Layout. The design
rules: `src/scss/CLAUDE.md`.
