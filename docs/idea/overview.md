CYBERCORE CSS is a pure CSS/SCSS cyberpunk design framework — zero JavaScript in the framework itself. It includes 150+ SVG icons, 14 UI components (buttons, cards, inputs, modals, terminals, etc.), 6 visual effects (glitch, neon borders, scanlines, noise, datastream), and utilities for layout, spacing, text, and animations. The demo site is React + Vite + TypeScript showcasing all components. Framework exports are dual: CSS for direct use, SCSS for customization via variables. Icons are individually tree-shakeable. All components support `prefers-reduced-motion` accessibility. Framework is framework-agnostic: works with any HTML/CSS project. Maintained by sebyx07, published to npm, hosted demo on GitHub Pages.
